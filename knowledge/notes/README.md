# 个人知识笔记

> 一文件一主题。文件名用中文短语，比如 `如何做竞品拆解.md`。

## 每篇笔记的骨架

```markdown
# 标题

> 摘要：一两句话讲清这篇解决了什么问题，索引里直接引用它。

## 我的结论

（先写结论，再写推导。这样三个月后你只看这一段就够。）

## 支撑与来源

（数据、引用、链接。写清出处，不要只留结论。）

## 待验证 / 存疑

（没想通的地方。这一节比结论更有价值，它标记了你的认知边界。）

## 更新记录

- 2026-09-23 建立
```

## 写作纪律

- **写给自己**：不解释你已经懂的东西。笔记的价值在于**下次不用重新想一遍**。
- **先结论后推导**：搜索时先看到结论就够用了。
- **允许不完整**：「待验证」比硬凑一个自洽的说法更有用。
- 想不清楚的别硬写，先起一个标题占位，在「待验证」里写下你的疑问，过几天再回来。
