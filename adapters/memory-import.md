# 把其他 AI 的记忆搬进 AIBrain

> 适用场景：你用过豆包、元宝、Kimi、ChatGPT、Claude 等好几个 AI，想把它们各自记住的「你是谁、你偏好什么、你在做什么」汇总到本地这个 AIBrain 仓库里，统一管、长期用。

## 核心认知：记忆到底在哪里

最关键的一句话：

**云端 AI（豆包、元宝、Kimi、DeepSeek、ChatGPT、Claude、Gemini）的记忆不存在你电脑上。** 它们把记忆存在厂商的服务器里，本机没有任何文件可以「一键读取」。所以：

- 能一键检测的，只有**本机确实有数据落地**的工具——典型如 WorkBuddy（`~/.workbuddy`）、Cursor（`.cursor`）、Coze / 豆包桌面客户端的数据目录等。这些能被 `detect.py` 扫到。
- 纯云端、数据只在对方服务器的 AI，**没有任何本地文件可读取**，只能靠「让那个 AI 自己把记忆导出来」再贴进来。

记住这个分野，下面三段式就顺了。

## 三段式方法

### 第一步：本地能读的直接读

运行检测脚本，它会只读扫描本机已知的 AI 数据目录（**不读任何内容、不写入被扫描位置**），把结果写进 `inbox/detected.md`：

```
python tools/detect.py
```

打开 `inbox/detected.md`，看命中了哪些位置、建议动作是什么（本地可导入 / 需手动导出）。

### 第二步：云端记忆靠提示词导出

对纯云端的 AI，去它的对话框里，把 **`给AI的指令词.md`** 里的提示词整个复制进去发过去，它会按六个小节输出结构化清单：

- 一、我是谁（基本信息）
- 二、我的偏好和习惯
- 三、重要的人
- 四、我正在做和待办的事
- 五、我定过的主意和原因
- 六、你不确定或可能过时的部分

那份提示词文件里还附带两段补充用法：发给豆包时追加的「我上传过哪些文件」提问，以及对方回答「我没有记忆功能」时的兜底话术。

多数平台也可以先在设置里查看或开关记忆（界面会变，以实际为准）：

- ChatGPT：设置 → 个性化 → 记忆（可开关、可查看/编辑已存条目）。
- 豆包 / 元宝：设置里的「数据与隐私」通常有「记忆 / 对话记录」查看或导出入口。
- 其他平台类似，先找「设置 → 记忆 / 个性化 / 数据导出」。

把 AI 返回的内容直接复制走，进入第三步。

### 第三步：落盘导入

1. 把导出的文本存成 `.md`（或 `.txt`），放进 `inbox/` 目录。
2. 先预览，确认将要合并的内容合理：

   ```
   python tools/ingest.py --dry-run
   ```

3. 确认无误后，去掉 `--dry-run` 正式导入（自动按分类合并进 `memory/` 等，并跑一次 sync）：

   ```
   python tools/ingest.py
   ```

## 各平台一行要点

| 平台 | 类型 | 操作要点 |
| --- | --- | --- |
| WorkBuddy | 本地可检测 | `~/.workbuddy/MEMORY.md` 等会被 `detect.py` 扫到，可直接并入 |
| Cursor | 本地可检测 | `.cursor` 配置目录会被检测；记忆需手动导出文本再落盘 |
| Coze | 本地可检测 | 桌面客户端数据目录会被检测；记忆需手动导出 |
| 豆包 | 只能提示词导出 | 设置→数据与隐私查看/导出；或在对话里用 `给AI的指令词.md` 的提示词 |
| 元宝 | 只能提示词导出 | 设置→数据与隐私查看/导出；或用提示词让其整理 |
| Kimi | 只能提示词导出 | 无本地文件，直接用提示词让其在对话里产出清单 |
| DeepSeek | 只能提示词导出 | 无本地文件，直接用提示词导出 |
| ChatGPT | 只能提示词导出 | 设置→个性化→记忆 可看可导出，也可用提示词 |
| Claude | 只能提示词导出 | 无本地文件，直接用提示词导出 |
| Gemini | 只能提示词导出 | 无本地文件，直接用提示词导出 |

## 安全提醒

导入进 `inbox/` 的内容会被 `ingest.py` 合并进仓库并随 sync 扩散。**不要贴入密码、身份证号、银行卡、账号令牌，以及他人的隐私信息（手机号、住址等）。** 若导出文本里夹带敏感内容，先手动删掉再保存。
